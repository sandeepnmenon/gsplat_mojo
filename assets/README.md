## Release blocker and safe remediation

Do not ship either asset in a source distribution, wheel, release archive,
documentation bundle, or website until one of these paths is completed:

1. Locate the original source and retain written evidence of the creator,
   rightsholder, exact license/terms, and permission for the project's intended
   redistribution and derivative render; then add the required attribution and
   license text here.
2. Obtain a direct written license from the rightsholder and archive the
   permission outside the repository as appropriate, recording its scope here.
3. Remove both files from release history/artifacts and replace them with a
   project-created or clearly permissively licensed scene. Record the complete
   provenance, generator/source files, license, and attribution for the
   replacement before adding it.

Until remediation is reviewed, the assets may remain useful for local
historical validation but are a release blocker. This document records facts
found in repository history; it is not legal advice.
